Политика конфиденциальности сайта

Эта политика описывает работу сайта nateelka.github.io и не заменяет политику приложения «План расходов».

О сайте

Разработчик Natəlka публикует здесь информацию о приложениях. Регистрация на сайте не требуется. Для связи доступен чат-бот поддержки.

Технические данные

При загрузке сайта GitHub Pages обрабатывает технические запросы браузера, необходимые для отображения страниц. Для отображения шрифта подписи разработчика браузер может загружать файл шрифта PT Sans с CDN jsDelivr (cdn.jsdelivr.net). При таком запросе CDN получает стандартные технические сведения сетевого соединения, включая IP-адрес.

Яндекс Метрика

С вашего разрешения используется Яндекс Метрика (счётчик № 113833393). Она помогает оценивать посещаемость страниц, источники переходов и нажатия на ссылки магазинов приложений. Могут обрабатываться cookie, технические характеристики браузера и устройства, посещённые страницы, события и IP-адрес. Подробности приведены в справке Яндекс Метрики.

Согласие и отказ

Без вашего согласия счётчик на сайте не загружается. Отказ не ограничивает работу страниц. Выбор сохраняется в localStorage браузера. Изменить его можно через настройки cookie. После отзыва согласия страница перезагружается. Ранее установленные cookie можно удалить в настройках браузера.

Хранение и изменения

Сайт не хранит собственную серверную базу посетителей. Данные Метрики обрабатываются в соответствии с условиями сервиса Яндекса. Политика может обновляться при изменении работы сайта. Дата обновления: 28 октября 2026 года.
