# Мои приложения

Разработчик: Natəlka.

Статический сайт для GitHub Pages. Платные сервисы, сборка и установка зависимостей не нужны.

## Просмотр до публикации

Откройте index.html в браузере. Главная, оформление и обе страницы приложений работают без сервера. В адресах папок браузер может показать список файлов; в таком случае откройте index.html внутри нужной папки.

## Страницы

- / — главная с каталогом.
- /apps/plan-rashodov/ — План расходов.
- /apps/family-health/ — Здоровье семьи, в разработке.
- /assets/style.css — общие стили.

## Добавить приложение

1. Скопируйте папку apps/family-health в apps/название-приложения.
2. Обновите заголовок, описание, возможности и статус в её index.html.
3. Скопируйте карточку article.app-card в главной и замените текст и ссылку. Сетка сама разместит новые карточки.

Не добавляйте кнопку скачивания до выпуска приложения. Декоративная иллюстрация главной условная. Иконка «Плана расходов» взята из официальной карточки RuStore. Галерея использует четыре новых изображения, предоставленных разработчиком для версии, проходящей модерацию. У «Здоровья семьи» пока условная иллюстрация.

## Сохранённые адреса

Корневой app-ads.txt оставлен побайтно без изменений. Не заменяйте его при публикации.
Ссылка на политику сохранена: https://nateelka.github.io/planrashodov-privacy/ . Политика не находится в этом репозитории; её содержимое и размещение не меняются.

## Публикация

Изменения подготовлены только локально. Отправка в GitHub и публикация допустимы после отдельного разрешения пользователя. Перед отправкой нужно проверить актуальность удалённой версии и убедиться, что app-ads.txt не входит в изменения. Существующие настройки GitHub Pages менять не требуется.

## Финальная галерея

Изображения скопированы без изменений из PlanRashodov_RuStore_1_9x16.jpg … PlanRashodov_RuStore_4_9x16.jpg в assets/plan-rashodov-new-1.jpg … assets/plan-rashodov-new-4.jpg. Порядок — 1, 2, 3, 4: бюджет, платежи, накопления, резервные копии. Перед публикацией после модерации разработчик должен сверить этот порядок и изображения с одобренной версией в консоли RuStore.

Просмотр: нажатие на изображение открывает диалог; «Увеличить» позволяет рассмотреть и прокрутить изображение. «Закрыть», Escape и нажатие вне окна закрывают просмотр. Без JavaScript ссылка открывает исходный JPG. Сторонние зависимости не нужны.

Публикация ожидает отдельного разрешения пользователя. app-ads.txt и репозиторий политики не изменяются.
